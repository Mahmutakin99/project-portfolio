# Learning Projects & Engineering Exercises

Smaller projects document the progression from language fundamentals to graphical interaction and layered application design. They are grouped here to keep the main portfolio focused on complete product workflows.

| Project | Scope | Practice demonstrated |
| --- | --- | --- |
| C | C/C++ calculator, ATM simulation, ideal-weight calculator, rock-paper-scissors, and dice exercises | Control flow, functions, input handling, and basic algorithms |
| Python | Small console utilities and games, including number/word guessing, Caesar cipher, QR generation, translation, notes, and password generation | Language fundamentals and library integration |
| Projects | Coffee-machine simulation, Pong, Snake, Flappy Bird, and quiz exercises | Classes, small-module composition, game loops, and simulation; overlaps standalone game repositories |
| ChatBot | Simple rule-based Python chatbot | Conditional response handling; not a trained language model |
| KuantumKaos | Console inventory simulation organized around base classes, interfaces, models, and exceptions | Object-oriented design, inheritance, and error handling |
| UstaPlatform | C# service-marketplace prototype with domain, infrastructure, pricing, and rule projects | Layered architecture, pluggable pricing rules, and loyalty discounts |
| Pong-Game | Python Pong implementation | Paddle/ball state, collision behavior, and scoring |
| SnakeGame | Python Snake implementation | Movement, food, collision, and score state |
| FlappyBird | Python/Pygame Flappy Bird clone | Input, obstacle movement, collision, and restart flow |
| QuizGame | Console multiple-choice quiz | Question models and answer/score control flow |
| ColorCatchGame | JavaScript browser color-catching game | Browser events and interactive game state |
| ZarAt | Swift/UIKit dice app | Auto Layout and simple interface actions |
| claude-code-statusline | Bash status line displaying workspace, Git branch, model, context, cost, and available usage limits | JSON input parsing with jq, conditional segments, ANSI color thresholds, and a settings installer with backup |

## Evidence and presentation boundaries

The catalogue is grounded in repository descriptions, README content, and file inventories. These are practice projects; current build success, production readiness, originality of familiar game concepts, and distribution are not claimed. The Projects repository overlaps several standalone exercises and is not counted as a separate finished product.

Source is kept out of this presentation. No verified screenshots were selected for this catalogue. Larger native and full-stack applications have individual case studies.

The status-line tool is a developer utility rather than a learning game. Its README documents missing-data omission and platform prerequisites; this catalogue does not assert compatibility with every current Claude Code payload or a newly tested installation.
